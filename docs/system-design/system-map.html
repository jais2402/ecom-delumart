Seven layers, outermost first. Each one assumes the one before it has already failed.

  1. EdgeEncrypted connections, firewall rules, bot challenge, rate limits.
  2. Sign-inNo passwords to steal. Email link or Google, a verified phone, and a fresh sign-in before anything sensitive.
  3. ApplicationOne permission check on every request. Input is validated and output is escaped.
  4. Business rulesRetry-safe payments, card PIN with lockout, and a 24-hour delay on irreversible admin actions.
  5. DatabaseIts own rules, independent of the app: a user can read only their own rows, money records cannot be edited, and every money entry must balance to zero.
  6. DataBirthdate and address are encrypted with a key kept outside the database. PINs and codes are stored only as hashes. No real payment data exists.
  7. DetectionA permanent log copied off-site, a daily money check that halts purchases on any mismatch, and an email on every admin sign-in.
