# DeluluMart documentation

| Document | What it is | Read it when |
|---|---|---|
| PRD v1.4 (PDF, not in this repository) | Original product requirements | You need the baseline rules |
| [prd-v1.5-revision.md](prd-v1.5-revision.md) | Changes on top of v1.4: cart, payment simulator, delivery, coupons, back office, identity, research, Super Admin | You need the current product rules |
| [system-design/system-map.html](system-design/system-map.html) | One-page visual: the whole system, a payment step by step, the security layers | You want the picture first |
| [system-design/low-level-map.html](system-design/low-level-map.html) | One-page visual of the low-level design: data model, pay transaction, postings, sequences, states | You want the build-level picture |
| [system-design/high-level-design.md](system-design/high-level-design.md) | Context, containers, modules, flows, deployment, trade-offs | You want the shape of the system |
| [system-design/low-level-design.md](system-design/low-level-design.md) | Schema, constraints, lock order, algorithms, state machines, API, jobs, security details | You are about to build something |
| [engineering-standards.md](engineering-standards.md) | Development approach, coding standards, testing strategy and test catalogue, review mechanism, skills and agents, cost control | You are about to write or review code |
| [design-system.md](design-system.md) | Daydream design system: tokens, atomic levels, component inventory, rules | You are building a screen |
| [decisions.md](decisions.md) | Choices made on the owner's behalf, and those only the owner can make | You want to check or reverse a default |
| [execution-plan.md](execution-plan.md) | Phases, milestones, exit gates, weekly rhythm, cut list, first ten days | You are deciding what to build next |
| [architecture.md](architecture.md) | Decision record: why each choice was made, alternatives, security threat model, research on other platforms | You want the reasoning or need to revisit a decision |

Order of authority when documents disagree: PRD revision → system design → decision record.
